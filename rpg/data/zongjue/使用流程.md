# 心法总诀 · 使用流程（行测各科目通用）

## 一共五份文件
| 文件 | 干什么 | 什么时候用 |
|---|---|---|
| 配置 · 空白模板 | 告诉 AI 这门课要蒸馏什么（目的、固定清单、任务方向……） | 每门课填一份 |
| 第一步 · 提取例题 | 从课程逐字稿里提取每道例题，只记老师说过的 | 每份逐字稿跑一次 |
| 第二步 · 归纳心法 | 把全部例题记录归纳成一套心法，并生成入口 SKILL.md | 例题记录攒够后跑一次；新增课程时用“更新模式” |
| 第三步 · 生成学习版 | 把例题记录改写成“学员自己能学”的学习版：每个知识点一章，先讲老师是怎么讲的，再讲例题怎么一步步做出来 | 想系统学习时，第二步之后（也可以只做这一步） |
| 使用流程 | 就是本文 | — |

## 流程
1. **填配置。** 复制「配置 · 空白模板」，按课程填好。记录类型选“判别型”（逻辑论证、片段阅读、定义判断、常识……对选项做判断）、“方法型”（数量关系、资料分析、图形推理……重点是怎么算）或“混合型”（逻辑填空：文段找对应 + 选项做辨析 + 实用技巧，既要判断选项又要用固定技巧；要把这三份清单分别抄进配置）。
2. **第一步（每节课一次）。** 在 GPT / Gemini / DeepSeek 等平台新开对话，发：`第一步文件 + 配置 + 一份逐字稿`（有例题的完整题目就一起发，AI 会以题目为准）。输出原样保存，叫“例题记录”。
3. **第二步（攒够再跑）。** 新开对话，发：`第二步文件 + 配置 + 全部例题记录`。输出很长，AI 会分几轮写，每轮回复“继续”。得到心法的全部文件和最外层的 `SKILL.md`。
4. **打成 skill 包。** 把 `SKILL.md` 和“心法”文件夹放进同一个文件夹，压缩成 `.zip`（或平台直接给你的 `.skill`）。
5. **导入到板块。** 回到本页，打开对应板块，点「📥 导入 skill」，选这个 `.skill` / `.zip`（也可以直接选单个 `.md`）。同名文件会被覆盖（旧内容留在历史里），其余文件不动。导入后，下一次解惑就按这里的内容讲。
6. **（想系统学习时）第三步生成学习版。** 新开对话，发：`第三步文件 + 配置 + 例题记录`（有第二步的心法就一起发，用来对齐名称）。得到 `学习版/` 文件夹，同样压缩后导入板块。`学习版/` 里的文件只供阅读，**不会自动读入讲题**，不占额度。
7. **随时修改。** 板块里的文件可以直接改、新建、改名、删除，每次修改前的样子都留在历史里，可以回滚。

## 跑之前的 5 项预检（避免“数量对不上、名字被改”）
1. **找讲义里的固定清单**：这门课有没有“N 种结构 / N 美 N 丑 / N 个题型 / N 大方法”这类固定名单？有就**逐项原样抄进配置**（“固定清单”栏），这是最重要的一项。
2. **老师口头提过的总数**也写进配置的“课程体系总览”，第二步会拿它核对数量。
3. **任务方向 / 题型**（支持、削弱、主旨、细节……）写进配置，名称固定。
4. 有完整题目就和逐字稿一起发给第一步。
5. 跑完第二步先看“给你的提示”第一行：类型数量和名称是否与配置一致？不一致先别用，把清单补上，用**更新模式**重排，不用重跑全部。

## 几条经验
- **总则决定一切**：配置里的“蒸馏目的”写得越具体，第二步越不会跑偏。
- **老师没说的就让它空着**：不补结构、不补名字，缺口会列在“待核对与缺口”里，等后面的课补。
- **例题越多越准**：只有 1 道题支撑的说法不会进通用标准。导学类视频例题少，别指望一次出完整心法。
- **学习版要想有“老师是怎么讲的”，第一步的“老师讲过的概念”要记得详细**：核心讲知识点的那几节课，用最新的第一步文件跑。
- **做题输出要短**：每题不超过 25 行；缺设问或选项的题，只拆论证，不编选项和答案。
- **references 和 学习版 文件夹里的文件只供查阅 / 阅读**，讲题时不会自动读入（板块里会标“仅查阅”）；其余文件加起来超过读取上限的，会标“未读入”，请精简。
- **新科目先小批量试**：先用 2～3 节课跑第一步，检查没问题再全部跑；方法型科目的模板还没有大量实测过，第一次用要多看一眼。
