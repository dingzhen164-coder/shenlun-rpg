# 洞府

## 十二经罗盘（3.2.x，纯代码，无需素材）
洞府“十二经”默认显示灵力罗盘（玫瑰图）：十二个扇区对应十二个模块，花瓣长度＝时长，外圈刻十二时辰，中心显示总时长与最勤模块；顶部可切回“法印”球。实现在 `web/beauty_compass.js`，颜色来自 app.js 的 `BOARD_COLORS`，想改样式改 `web/beauty_ui.css` 里 `.cp-*`。
