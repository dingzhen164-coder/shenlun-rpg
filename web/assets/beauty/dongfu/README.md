# 洞府

## 十二经经络图（3.2.x，已接入）
洞府“十二经”默认显示人体经络图（顶部可切回“法印”球）。人体图与穴位位置都可以换，**放了就用，没放用内置剪影**：

| 文件 | 说明 |
|---|---|
| `meridian-body.svg` | 你找的开源人体图。要求：SVG，`viewBox="0 0 100 120"`（宽100、高120，人物居中站立、头在上），线条/填充随意（程序会把它放在经络线下面；想让它随主题变色，用 `currentColor`） |
| `meridian-nodes.json` | 12 个穴位的位置，格式 `[[x,y],[x,y],…]`（共 12 对，坐标按上面的 100×120，顺序＝模块顺序）。人体图换了以后，把穴位摆到图上合适的位置 |

内置默认穴位位置（可参考）：`[[50,10],[50,23],[29,35],[71,35],[50,47],[17,58],[83,58],[50,67],[38,90],[62,90],[38,113],[62,113]]`。
素材来源与许可证请登记到 `../REGISTRY.md`（需允许随程序分发，如 CC0 / CC-BY / MIT）。
