# 音频（授权素材，由你自行放入）

程序启动时按下列**固定文件名**查找，缺文件就静音，不报错。默认可关，答题时静音或降低（设置里可调）。
放入后在 `REGISTRY.md` 登记来源与许可证（必须允许随程序分发）。优先 ogg；大小：音效 ≤200KB，音乐 ≤3MB。

## bgm/（背景音乐，可循环）
| 文件名 | 用途 |
|---|---|
| `map-day.ogg` | 地图白天 |
| `map-night.ogg` | 地图夜晚 |
| `dongfu.ogg` | 洞府 |
| `study.ogg` | 学习/答题（低音量） |
| `ceremony.ogg` | 突破/升级仪式 |
| `dialog.ogg` | 对话/剧情（可选） |

## sfx/（音效）
| 文件名 | 用途 |
|---|---|
| `click.ogg` | 通用按钮点击 |
| `hover.ogg` | 地点牌悬停 |
| `open.ogg` / `close.ogg` | 弹窗开关 |
| `page.ogg` | 页面转场/翻页 |
| `correct.ogg` / `wrong.ogg` | 答对 / 答错 |
| `combo.ogg` | 连击 |
| `reward.ogg` | 领取奖励 |
| `levelup.ogg` | 升级 |
| `breakthrough.ogg` | 境界突破 |
| `quest-accept.ogg` / `quest-done.ogg` | 接取 / 交付任务 |
| `type.ogg` | 对话打字机（短促） |
| `ambient-*.ogg` | 环境声（风、虫鸣、水声，可选） |
