# 美化素材总目录（beauty）

## 想自己换素材？先看“美术文件夹”（推荐，不用改源码）
库里的 `训练/外观/美术/` 是专门放外观设计文件的文件夹：首页全景（白天、夜晚）、每个子地图的背景、人物立绘、背景音乐、音效，按中文名放进去、刷新网页就生效，删掉就恢复程序自带。
在 设置 → 外观与音乐 点“导出程序自带美术（当模板）”，会把自带文件按名字复制过去，改哪个换哪个。名字表和用法见该文件夹里的“说明.txt”，实现见 `rpg/art.py`。
下面这个目录（`web/assets/beauty/`）是**程序自带**素材的存放处与登记表，给开发者/其他 AI 用；日常换图请用上面的美术文件夹。

3.2.x 美化系列的**所有新增素材**统一放在这里，按类别分子文件夹。你自己或其他 AI 要更新素材，只看这一个目录。
旧素材（`web/assets/sect`、`guide`、`shenlun`）暂不搬动，仍由 `REGISTRY.md` 登记。

## 目录
| 子文件夹 | 放什么 | 格式 |
|---|---|---|
| `icons/` | 全站统一图标（开源图标统一调色后） | SVG，单色，用 `currentColor` |
| `materials/` | 按钮、卡片、弹窗的纸、玉、金边等纹理 | WebP/SVG |
| `fonts/` | 标题字体（离线分发，先查许可证） | woff2 |
| `cursors/` | 主题鼠标光标 | SVG/PNG |
| `ui/` | 加载页、启动画面、空状态插画、徽章、头像框 | WebP/SVG |
| `scenes/<主题>/` | 全景、时间段、季节变体、动态层素材（云、光点、鸟） | WebP/PNG |
| `characters/<主题>/` | 立绘、表情、站位小立绘 | 带透明通道 WebP |
| `dongfu/` | 洞府五页背景、经络图、背包格子、物品图标、境界徽章 | WebP/SVG |
| `effects/` | 突破、升级、奖励飞入等特效贴图 | WebP/PNG |
| `audio/bgm/` | 背景音乐 | ogg 优先（mp3 也可） |
| `audio/sfx/` | 音效 | ogg 优先 |

主题文件夹名：`xingce`（行测/修仙）、`shenlun`（申论）、`fakao`（法考）。行测先做，申论、法考后续同名子文件夹补。

## 更新素材的步骤（人或 AI 都适用）
1. 按各子文件夹 README 的**文件名约定**放入文件（同名覆盖＝换新）。缺文件时程序自动用占位或静态退路，不会报错。
2. 在 `REGISTRY.md` 追加（或修改）一行：编号、路径、用途、来源、授权、日期、生成提示词。
3. 体积不超预算：背景 ≤350KB，立绘 ≤250KB，图标 ≤20KB，单个音效 ≤200KB，单首音乐 ≤3MB。整套新增美术建议 ≤30MB。
4. 原始大图、PSD、原 PNG 不进仓库，只放转换后的文件。
5. 第三方素材先核对许可证并写进登记表；限制性授权不得入库。

## 给其他 AI 的说明
- 程序按**固定文件名**读取素材，清单见各子文件夹 README；不要改文件名，要换图就覆盖同名文件。
- 新增一类素材前先在对应 README 加条目，再写代码引用；代码里一律提供缺图退路。
- 修改后跑 `node tests/ui_layout_check.cjs --only=页面 --sizes=desktop --themes=light` 检查页面不破。
