# 公考模拟器图标

使用内置图像生成工具制作，独立生成，不使用第三方图标。设计提示：公考模拟器，行测与申论合并；唯一文字“公考”，字形准确、粗笔画、居中醒目；深墨蓝底与暖金字，简洁书卷和笔尖、小量青玉云雾，圆角边框，不含其他文字、官方徽记或水印。对应logo-brand用途。

生成结果仅进行尺寸及格式转换：icon-512.png用于Mac/PWA，icon-192.png用于PWA和网页顶栏，apple-touch-icon.png为180px，favicon-32.png为32px，app.ico含16/24/32/48/64/128/256px；Android五种密度48/72/96/144/192px使用同一图源。

图像转换是打包准备，不新增程序运行依赖；新程序的资源查询参数使网页重新获取图标。Mac由PyInstaller将512px PNG转换为ICNS。修改应用名称不改安卓包名和签名、Mac bundle identifier或旧数据路径。
