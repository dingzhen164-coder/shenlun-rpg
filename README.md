## 3.0.6开发批次：手动阶段奖励与功能合并

- 模考/考核成绩严格高于录入前预估分时登记一次待领取奖励，不再直接补足总修为。领取时使用当前小境界完整突破成本：凡人/炼气（法考对应平民/学徒及申论对应入门阶段）100%，筑基及以上对应阶段50%。不设固定3,000上限；奖励不计实际学习时长与天道进度，境界仍需手动突破。

## 三、常见问题

- **双击闪退 / 提示没有 Python**：回到第 1 步，确认勾了 “Add Python to PATH”，装完重新双击。
- **浏览器没自动打开**：看黑色窗口里的地址（`http://127.0.0.1:8766/`），手动粘贴到浏览器。
- **识别不到题 / 版式不支持**：不同机构的文档版式不一样，把文件发给开发者适配。
- **采分点要改**：直接在 Obsidian 里打开 `训练/采分点/某题.md` 改，格式见文件里的例子；
  每行 `- [分值] 名称 | 关键词: 词1；词2 | 依据: 第几段`，所有分值加起来要等于总分才能定稿。
- **AI 批改失败**：多半是 key 没填或没网；网页会提示原因，这次不计分、不进记录，重试即可。

6. 每次模考出分后到**修仙录**记录宗门大比：最近两次的较低分若高于当前道行，修为直接补上（可以直接跨好几层）。

   连续扛过几道天雷才能突破；失败会道基受损，冷却 3 天并先疗伤。
8. 落后天道进度时多做几道题追上（3.0 起去掉了丹房）；今日功课、修炼进度、灵根、心魔榜、储物袋都在**修仙录**里。
9. 有事修炼不了：修仙录里用**告假玉简**（每月 4 份）。累了直接在对话框说“好累”，师尊会先安慰你。
10. 营地 / 洞府点“向师尊请教”：问方法、让她帮你分析现状排计划，她看得到你的全部进度。

**换 AI**：设置 → 🤖 当前 AI。几套 AI（接口地址 + 模型 + key）各「存为一套」，下拉一选就切换；「常用接口」可一键填好 DeepSeek、通义千问、Kimi、智谱、硅基流动、OpenAI 的接口地址。

### 五、常见问题

- **修炼时间怎么算**：只有打开一项功课（背诵、论道、试剑、斩心魔、渡劫、炼丹……）并且在操作时才计时，做完看解析的 3 分钟也算；
  只是开着网页、看面板、和师尊闲聊不算。顶栏的计时器在计时时会亮起闪烁。线下做题的时间到“洞府 → 演武 · 历练记”手动补录。

- **打不开 / 闪退**：用终端运行 `python server.py`（Mac 用 `python3`）看报错。需要 Python 3.8 以上。
- **提示另一台电脑在用**：两台电脑同时开会让坚果云同步冲突，先关掉另一台上的程序（10 分钟后提示自动消失）。
- **提示有冲突副本**：`训练/存档/` 里出现带“冲突”的文件，说明两台同时写过。保留较新的那份，另一份删掉。
  每天第一次保存前都会自动备份到 `训练/存档/备份/`（保留 14 天）。
- **图形推理**：程序自带薛睿图推 24 诀功法（`训练/骨架/图形推理.md`），每一诀练三件事——适用图形的特征、口诀原句（一字不差）、口诀翻译。
  第一次运行会复制成草稿，对照原资料核对完标 ⚠ 的地方再定稿。
- **资料分析**：程序自带“题型识别 + 公式速算”功法（`训练/骨架/资料分析.md`，第 3 批），一个 `##` = 一种题型，每种练两件事——
  【识别】看到题干哪些信号就知道是这个题型；【公式】/【速算】这个题型的公式和简便算法。`> 真题例：` 行是原资料的真题题干，不判分。
  试剑是“识别速答”：师尊只出一句题干，你说出题型、识别依据、公式、速算方法，不用算数。
  如果库里已经有按 skill 生成的 `资料分析.md`，不会被覆盖，程序自带那份会放在旁边叫 `资料分析.程序自带版.md`，想用就改名替换。
- **常识**：目前是“副线”，只统计模考实战正确率；常识知识库、错题自动归档在第二版（见 DESIGN.md 路线图）。

### 📘 藏经阁 · 心法 / 办事规程（3.5.3）
每个板块有一份自己的心法（skill），**一开始都是空的**。你可以自己写，也可以把在别的平台（GPT / Gemini / DeepSeek 等）生成好的 skill **导入进来**；之后解惑、复盘追问时，师傅就按这里的内容讲。

- **书架**：一板块一本古籍；最前面还有一张「📜 总诀」卡。空板块的书是灰色封面，写着“空”。
- **看、改**：点开一本书，左边是文件列表和“解惑时会读到多少字”，右边阅读（公式、表格已渲染）。「✎ 修改」直接改原文，Ctrl+S 保存；保存后下一次解惑就按新内容讲。没有“原版 / 我的版本”之分，每次修改前的样子都留在「🕘 历史」里，随时回滚。
- **新建文件 / 改名 / 删除**：都在顶部按钮；改名、删除前的内容也进历史。入口文件叫 `SKILL.md`（排在最前，不能改名）。
- **导入**：点「📥 导入 skill」，直接选别的平台生成的 **`.skill` 文件**（它其实就是一个压缩包，不用解压；`.zip` 也行，也可以选单个 `.md`）。程序把里面的 `.md` 文件放进这个板块：同名文件覆盖（旧内容留在历史里），包里没有的现有文件不动；yaml、json 等非文字说明会跳过并告诉你。`references/` 和 `学习版/` 文件夹里的文件只供查阅 / 阅读，**不会自动读入讲题**（板块里标“仅查阅”），所以把篇幅很大的资料和学习版放那里最省额度。
- **📜 心法总诀**：五份可以复制到别的平台用的说明——蒸馏第一步（从课程逐字稿提取例题）、第二步（归纳成心法并生成 SKILL.md，做题用）、第三步（生成**学习版**：每个知识点一章，先讲老师是怎么讲的，再讲例题怎么一步步做出来）、配置空白模板、使用流程。点进去可以「📋 复制全文」或「⬇ 下载 .md」。完整做法：填配置 → 第一步（每份逐字稿一次）→ 第二步（攒够再跑）→ 得到 `.skill`；想系统学习就再跑第三步得到 `学习版/` 文件夹；一起回来导入到板块。
- 读取上限 6 万字符；超出的文件会标“未读入”，请精简或放进 `references/`。
- 旧存档照常使用：你之前在 训练/技能 里改过的文件还在；库里原来的 `copilot/skills` 不再自动读取，要用就导入。

### 📅 每日文章（仅申论，在时政简报里）

- **🔍 一键精读**：AI 提炼 主旨 / 核心观点 / 论证脉络 / 金句 / 可用素材 / 适合练的题型 / 运用思路，存到 `训练/时政文章/精读/`；金句必须是原文里真有的句子；「🧧 刻成便笺」把金句和素材放进 综合分析 › 每日文章。
- **阅读与记笔记**：打开文章就能用公务手账的笔、荧光笔、橡皮、撤销 / 重做勾画正文，在右侧和页底留白记心得；「文字心得」支持打字。手写笔写字，手指可设为只翻页（首次用笔自动切换），电脑鼠标也可写。正文使用22号画布字体，每页30行，常见千字文章最多两页，按固定比例分页，换屏幕后笔迹仍对准原文；可收起AI精读或全屏写。
- **自动保存**：每篇文章一本「文章批注」手账，存在 `训练/手札/手写/`，工具栏显示保存状态，失败可点击重试。返回文章或进入「公务手账」可继续写；「导出PDF」含原文、批注和文字心得。删除文章不会删除批注本。原文快照不随文章修改重新排版，旧存档照常使用。2.4.0文章批注本打开时自动紧凑排版，已写的笔迹原样留在手账的「旧版批注」，不挪动旧笔迹；文字心得保留。两台设备请勿同时编辑同一本；遇到版本冲突时，先保留未保存内容，再重新打开。
- 网站改版后某个来源可能失效，界面会提示；换个来源或粘贴链接即可。

### 六、顺序真题实战

启动时自动创建 `训练/题库/`，包含现有 12 个板块的空白真题 Markdown 模板。
打开如 `论证逻辑真题.md`，将代码块内示例复制到代码块外，替换为你的真题。
每题用 `## 题目 固定编号`，包含 `### 知识点`、`### 题干`、`### 选项`、`### 答案`、`### 解析`；
选项是 A/B/C/D 单选，答案小节只写一个字母。每个板块内编号唯一、固定，程序按文档出现顺序做题，不按编号大小排序。
材料题将共同材料复制到各子题题干。

**批量入库**：模考试卷统一到“宗门大比 → 录入 → 01 试卷导入”；练习册与题库维护仍在藏经阁“经卷 · 题库 → 导入真题”。
- **模考PDF**：选择PDF，点“开始导入”。原xingce-mokao-split/pymupdf管线拆成板块复盘再入题库。新文件保存在`训练/模考试卷/`，复盘保存在`训练/模考复盘/第N季/`，旧复盘优先保留；季号可从文件名识别或手填。“已保存PDF与拆分组件”里可补拆、检查/补导入已有季。
- **模考HTML**：选择粉笔保存的完整HTML；同名`_files`文件夹压成ZIP选在“配套资源”，也可以把HTML和文件夹一起压成完整ZIP直接选择。先点“检查HTML / ZIP”，题目和图片齐全后再点“开始导入”。缺图或网页只保存了部分题目时会提示补齐，不导入残缺题。HTML无需PDF拆分组件，不执行网页脚本、不联网取图片。保留原题、解析、材料和原答题对错；不会自动替你录入成绩。
- **逐题用时与核分（开发补丁）**：HTML读取原答题用时，在复盘的答案后、解析前显示；已导入的同季重新检查并导入，可补齐用时而不改旧笔记、不重复计时。成绩单同时显示HTML报告分与参考估分，默认保留已录分，其次填HTML报告分；参考表与粉笔可能不同（这份39季为70.45与70.6）。可选择填入并核对后保存，导入本身不录分/发奖。PDF若没有逐题对错，先补答题卡；参考分值/题量可在训练/规则.md修改。
- **录入分组**：01试卷导入、02答题卡与对错、03成绩单各自展开，默认收起。已保存的PDF模考也使用同一入口；同季重复导入不重复入题库、不重复记120分钟。成绩草稿折叠后仍保留，旧存档照常使用。
- **txt**：练习册、真题卷的 OCR 文字。选文件，填编号前缀（如“四海逻辑600”），来源能认出就自动写，练习册勾“没有来源”。
- **PDF（有文字层）**：WPS / Word 导出的、或 OCR 软件生成的“可搜索 PDF”，在同一处直接选。比转 txt 多保住逻辑填空的横线（写成 `____`）和双空选项之间的空格。“拔高刷题十一”“练习题16”这类标记按里面的数字分套。扫描图片 PDF 没有文字层，要先 OCR 成可搜索 PDF。需要 pymupdf（① 里的“安装拆分组件”）。
  能干净拆开的题直接入库，拆不干净的放进 `训练/题库/_待修/<名称>.md`：在 Obsidian 里改好、清空那道题的“### 检查”，回来点「重新导入」；修不了就删掉。
  粉笔试卷的 OCR 文字顺序会乱，请改用上面的“模考”方式。
- **补答案**：练习册答案在另一本时。整本一次补：前缀填导入时的前缀（如“花生600题”），答案每行一套“练习01 ADDBA CDCAB DBBCC BBADD”；
  只补一套：前缀写到第几套（如“花生600题-03”），答案写“1-5 ABCDA”或“1.A 2.B”。练习册按每套开头的“练习题NN”分套，套号和答案表对得上。
- **撤销一批**：导错了想重导时，填编号前缀删除这批还没做过的题（做过的有作答记录，保留）。
- **知识点**：按问法自动猜（削弱、加强、真假推理……），猜不出写“待分类”，不影响做题；设置了 DeepSeek 可以点「AI 补 100 题」，
  只发题干给 AI（有骨架的板块用骨架的大项名），几百道题几毛钱。
- 想让 AI 精修个别题时，还可以用 obsidian-to-xingce 仓库的 `xingce-tiku` skill（费 token，一般用不到）。
- **图**：图形推理、资料分析的图放在 `训练/题库/图片/<板块>/`，题干里写 `![[训练/题库/图片/图形推理/编号.png]]`，试炼时会显示图片。
- **答案待补**：`### 答案` 写“（待补）”的题先不出，题库页显示“待补答案 N 道”。
- **解析待补**：`### 解析` 可以写“（待补）”，作答后显示“解析待补”，之后再用 skill 补。

在 **试炼塔** 选择每组 10 或 15 道，出题可选「按顺序 / 🔀 乱序」（板块试炼和知识点试炼共用；乱序从还没做过的题里随机抽，做过的照样不出）；当天有骨架训练的板块会在最后一项知识训练后插入实战功课。

**补蒸馏解析**：导入页「⑨ 补蒸馏解析」填本机蒸馏笔记文件夹（每题一篇、frontmatter 有 qid 的“考公脑库”格式），

**原题副本（政治理论 / 常识 / 言语 / 数量，1.5 万余题）**：来自 github.com/ERRRC/xingcezhenti。
`python -m rpg.zhenti --raw <仓库目录> <输出目录> [已有题库目录]` 生成 `<板块>真题-<年份>.md`（按年份拆）并把用到的图拷进 `题库/图片/真题库/`。

错题自动收录，可从该板块的 **错题复练** 入口练习；默认连续正确两次移出待复练，历史不删除。
首次正确率、复练正确率、每组正确率单独显示，既有模考正确率与灵根判定保持原有口径。
实战不需要 AI，时间计入原有每日 120 分钟目标；首次作答及新题组通关按规则发修为，复练不重复发放。

### 生成功法草稿读哪些资料

藏经阁“生成草稿”会读板块解题 skill，**以及 skill 里用反引号引用的库内资料**：比如政治理论 skill 引用的 `政治理论/00-三层级做题总框架.md`、`01-治理母逻辑` 文件夹、检索 skill 文件夹里的资料。skill 里“读哪个文件、调用哪个检索、输出格式、调度”这类写给 AI 的操作规程不会进骨架。
草稿开头会写“生成时读到的资料：……”。读得不对或缺了，在 `训练/规则.md` 加一行 `- 骨架素材.政治理论: 政治理论/00-三层级做题总框架.md, 政治理论/知识库`（库内路径，文件或文件夹，逗号隔开），再点“重新生成草稿”（未定稿的草稿会先备份成 .bak.md）。

### 每日功行 = 修炼 + 听道

每日目标默认 300 分钟（`规则.md` 的“每日目标分钟”），由两部分合计：
- **修炼**：在本程序里做功课的时间，自动计时（只算真正在做题 / 默写 / 论道的时间；在 🪶 手札里写字也算复习，停笔超过 1 分钟就不再计）。
- **听道**：在其他平台看网课的时间，首页「📿 听道 · 闻法记」手动记一笔（可选 30/60/90/120 快捷分钟、写讲的什么、补记最近 7 天、记错可删）。
打卡（周天不息）、道心、周常的功行分钟、导师“今日达标”都按合计算；听道每分钟给 0.5 修为（`经验.听道每分钟`），修为主要还是靠修炼。
旧版规则里仍是默认的“每日目标分钟: 120”“周常.修炼分钟: 600”会自动改成 300 / 1500，自己改过的值不动。


### 完整真题与综合批改（2.5.0）

打开「档案室 → 题库 · 采分点」或「实战」中的「完整真题」。首次点「下载并录入公开申论题库」，约330MB；需要能访问GitHub，后台显示进度，失败可重试，已校验的文件会复用。当前固定源版本包含909套、3458题（包含回忆卷及少量不完整题），不是程序自带数据。也可展开「手动录入一道题」，粘贴题干、对应材料、分值、字数上限和可选参考答案；或者下载JSON格式模板，导入整卷或多卷。重复标题及来源视为同卷，保留已录入资料。

按地区、年份、题型选择题目，在材料旁写答案或粘贴已经写好的报告。草稿自动保存；交卷前先保存，并使用「设置」中配置的AI综合批改。材料、题干、答案会发给该AI服务。评价标准首次仅根据题干材料生成，以后同题沿用；AI判断含义和档位，程序算训练建议分。批改提供材料依据、你的原句、任务/结构/表达及应用文专项检查、修改建议。修改答案再次交卷，可以比较进步与退步。历史作答可重开，完整答案与复盘写入「训练/作答/综合」，支持Obsidian查看。

批改方法保存在「训练/批改方法.md」，可以自行完善；权重在「规则.md」配置。方法及权重修改对新生成标准生效，已作答题保持原标准以便比较。题库JSON位于「训练/题库/申论真题」，缺少材料或分值可在Obsidian中补全后刷新。公开库题干出现材料ID时，它不等同材料序号；页面会保留整卷资料，请按题干内容核对对应材料。已有标准的题干或材料变更会阻止沿用旧标准，请先核对并移走该题的「训练/采分点/综合/<qid>.json」，之后会生成新标准；不同标准的历史分数不作直接对比。旧采分点练习继续兼容。

公开数据来自 [ERRRC/kaogong-shuati](https://github.com/ERRRC/kaogong-shuati)，固定版本 `12cf8e73be8fd18f615782e7a5748b0ca7f39ce2`，使用只读SQLite连接；来源库解析属于参考资料，非官方评分标准。下载、材料、解析只保留在个人本地库，不提交或打包到本项目。新批改方法独立编写，参考了语义覆盖、引用校验、固定量表和多稿反馈的思路，未复制GPL代码或文本。
