# 申论官途（shenlun-rpg）

把申论备考做成“公文官场”主题的本地训练网页：**采分点批改** + 职级成长。
只在你自己的电脑上运行（浏览器打开 `127.0.0.1`），数据放在你的 Obsidian 申论库里，AI 用你自己的 DeepSeek key。

- 姊妹项目：[xingce-rpg](https://github.com/dingzhen164-coder/xingce-rpg)（行测修仙传），日后合并
- 开发者 / AI：先读 [AGENTS.md](AGENTS.md) 和 [DESIGN.md](DESIGN.md)

---

## 一、第一次使用（Windows，约 5 分钟）

1. **装 Python**（装过就跳过）：打开 https://www.python.org/downloads/ 下载安装，
   **安装界面最下面一定要勾上 “Add Python to PATH”**。需要 3.8 以上版本。
2. **下载项目**：GitHub 仓库页 → 绿色 **Code** 按钮 → **Download ZIP**，解压到任意文件夹（比如桌面）。
3. **启动**：双击 **`启动申论官途.bat`**。会弹出一个黑色窗口和浏览器页面。
   黑色窗口不要关，关掉 = 退出程序。
4. **设置**（左侧栏最下面）：
   - 填 **DeepSeek API Key**，点“测试连接”看到“连接成功”就行；
   - **申论库文件夹**填你的 Obsidian 申论库路径，比如 `C:\Users\29356\Desktop\申论obsidian\申论`
     （在资源管理器地址栏复制）。程序会在里面建一个“训练”文件夹存数据。
5. **导入题**：左侧“导入解析文档” → 选真题解析 PDF → 题目编号前缀填个名字（比如 `国考2026-副省`）→
   看识别结果 → 点“让 AI 起草采分点”。
   第一次导入 PDF 如果提示缺组件，点页面上的“安装 PDF 读取组件”（需要联网，只装一次）。
6. **审定**：左侧“题库选题” → 点一道题 → 点“审定并定稿”（草稿状态也能先试批，只是不计入预估分）。
7. **作答**：在题里写答案 → “交卷批改”。结果里能看到每个采分点是否落实、依据句、失分类型和批示。
   每次批改会自动在 `训练/作答/日期/` 存一份复盘文件，Obsidian 里直接能看。

Mac：把第 3 步换成双击 `启动申论官途.command`（第一次若提示无法打开：右键 → 打开）。

## 二、更新

双击 **`更新.bat`**（Mac：终端运行 `python3 update.py`）。它会下载最新代码覆盖程序文件，
**你的数据（申论库里的“训练”文件夹、设置、API key）都不会动**。更新完关掉黑色窗口，重新双击启动。

只想看有没有新版：`python update.py --check`。

## 三、你的数据都在哪

| 位置 | 内容 |
|---|---|
| `<申论库>/训练/资料/` | 你导入的解析文档副本 |
| `<申论库>/训练/采分点/` | 每题一个 .md，可以在 Obsidian 里直接改（改完回网页刷新） |
| `<申论库>/训练/作答/` | 每次批改的复盘 |
| `<申论库>/训练/存档/` | 练习记录（每天自动备份，保留 14 份） |
| `C:\Users\你\.shenlun-rpg\settings.json` | API key、库路径（只在这台电脑，不进仓库） |

没设置库路径时，数据放在程序旁边的 `data/` 文件夹。

## 四、常见问题

- **双击闪退 / 提示没有 Python**：回到第 1 步，确认勾了 “Add Python to PATH”，装完重新双击。
- **浏览器没自动打开**：看黑色窗口里的地址（`http://127.0.0.1:8766/`），手动粘贴到浏览器。
- **识别不到题 / 版式不支持**：不同机构的文档版式不一样，把文件发给开发者适配。
- **采分点要改**：直接在 Obsidian 里打开 `训练/采分点/某题.md` 改，格式见文件里的例子；
  每行 `- [分值] 名称 | 关键词: 词1；词2 | 依据: 第几段`，所有分值加起来要等于总分才能定稿。
- **AI 批改失败**：多半是 key 没填或没网；网页会提示原因，这次不计分、不进记录，重试即可。

## 五、开发

```bash
python server.py                              # 启动
python -m unittest discover -s tests -v       # 测试（用假 AI，不联网、不花钱）
python -m subjects.shenlun.analysis 文档.pdf --prefix 前缀 --list   # 命令行查看识别结果
python -m subjects.shenlun.grader 文档.pdf --prefix 前缀             # 用参考答案标定采分点
```
