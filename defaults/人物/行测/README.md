# 行测宗门人物

每人一个固定ID目录，可修改人物卡、语录和立绘。程序仅补缺失文件，不覆盖已有内容。

有效活动地图：home行测宗、train问道群峰第一层、peak-chang万象峰、peak-yan辨言峰、peak-li明理峰、peak-shu演数峰、peak-zi观星峰、bank试炼塔、contest宗门大比、skeleton藏经阁、tianji天机台。

洞府、手札、设置、答题与手写等深层界面不出现人物。地图上的“偶遇”人物头像可点击；主界面为四分之三身，交流/论道为半身。没有图时使用姓名标记，之后再放图片即可。

“人物卡.md”使用“- 键：值”。人物ID保持不变；姓名、身份、启用、活动地图、论道板块、喜欢礼物、不喜欢礼物、立绘路径与性格可以改。AI性格从立绘章节之前的设定读取；文件最长100KB。语录文件也支持编辑。改卡后重新打开人物，下一条回复使用新设定。

赠礼从原储物袋取一件物品，界面明确列出扣除，收礼记录和剩余数量一起保存；不会发额外经验。没有物品时不能赠礼。喜好属于游戏设定，默认未设时反应为普通，可自己修改。

每人聊天和记忆相互独立。自由交流允许闲聊；论道使用该人物对应知识骨架目录与上下文，不代替正式批改。AI只读最近12条和手动记忆，不自动扫描题库或笔记，不自动调用摘要。全部原文保留，可在对话框查看；可用“人物记忆”留下重要约定。

此包角色以公开教学形象启发；未经核实的性格明确为创作候选，游戏对话不代表真人发言。
