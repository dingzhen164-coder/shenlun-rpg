# 公考行测本地 Agent 规则（gk-skill / Obsidian 行测库通用）

本文件用于指导本地 AI Agent（Claude Code / Codex / Cursor 等）在用户的行测学习库与 `gk-skill` 中记录题目、整理讲义、检索时政与同步「公考模拟器（行测修仙传）」的数据。

---

## 一、行测库 `训练/` 目录结构（4.4.0 六大类重排）

行测库下的 `训练/` 目录已按「4 个修仙地点 + 2 个系统底座」统一归为 **6 个一级文件夹**，请勿再向 `训练/` 顶层散落旧文件夹：

1. **`训练/思过崖/`**：思过崖 7 板块错题文档（`逻辑填空.md`、`片段阅读.md`、`图形推理.md`、`定义判断.md`、`类比推理.md`、`逻辑判断.md`、`数量关系.md`）、`assets/` 错题配图、`_模板.md`。
2. **`训练/万象峰/`**：
   - 内部系统数据：`期刊/`、`知识地图/`、`消化/`、`重点标红/`、`词义批注/`、`简报/`、`回收站/`
   - **各时政地图导出的 `.md` 文件夹**：`训练/万象峰/<时政地图名>/`（下设 `月半时政/`、`专题时政/`、`冲刺学习/` 三个子文件夹，保存对应时政地图时间范围内的 `.md` 文档；同步时也会镜像到 `gk-skill/时政地图/<时政地图名>/`）
   - **政治理论易错题集**：`训练/万象峰/易错题.md`（同步自 `gk-skill/错题集/政治理论.md`）
3. **`训练/藏经阁/`**：`题库/`（刷题题本与板块题库）、`技能/`、`成语实词录/`、`灵脉图/`、`骨架/`、`卡片/`（玉简）。
4. **`训练/试炼与大比/`**：`模考试卷/`、`模考复盘/`、`试炼记录/`、`演武录/`、`静修录/`、`手札/`。
5. **`训练/规则与设定/`**：`规则.md`、`角色设定.md`、`台词库.md`、`台词库·玄幻.md`、`语录.md` 及顶层人物头像（如 `师尊.png`）。
6. **`训练/系统/`**：`存档/`、`外观/`、`人物/`、`历史备份/`（含 `词录备份/`、`导入回收/`、`更新备份/`、`清除/`、`修炼记录/`）。

## 二、数量关系题目分流规则（十八讲 vs 思过崖错题集）

用户经常一次发**整套数量关系训练题**或**讲义例题**。处理数量关系题目时，必须严格执行以下分流规则：

1. **所有正常数量关系题目 → 归入「数量关系十八讲」对应 `.md` 文档**：
   - 无论做对、做错还是未作答的常规训练题，均按题型分类记录到「数量关系十八讲」对应的课程 `.md` 文档中（`第01课-方程思维.md` ～ `第18课-趣味杂题.md`），用于题型方法体系沉淀。
2. **只有「错题」和「慢题」才计入 `错题集/数量关系.md`（思过崖）**：
   - **计入条件（满足其一即可）**：
     - 做错的题（`我的选择` 与 `正确答案` 不同）；
     - 不会做 / 未做出 / 蒙对 / 猜对的题；
     - **慢题**（用时偏长、超时的题，请在标题或诊断中标注 `[慢题]` 或具体耗时）；
     - 用户明确说明有思维卡点、需要进错题集反复重做的题。
   - **严禁计入**：正常做对且用时正常、无卡点的常规训练题或纯讲义例题，**一律不得写入 `错题集/数量关系.md`**（只记入十八讲对应文档）。
3. **十八讲目录归属格式**：
   - 写入 `错题集/数量关系.md` 的每道错题/慢题，必须在 `### 题源与归属` 中注明 `- **所属课程**：第XX课-XXX`（严格对应十八讲目录名称，如 `第01课-方程思维`、`第08课-最值问题` 等），以便思过崖左侧按十八讲目录可展开显示。

## 三、万象峰时政地图规划与政治理论检索规则

### 1. 时政地图的时间范围与归档规则
每个时政地图都有明确的**时政时间范围**（可在万象峰「政治理论 → 管理时政地图」中新增、编辑范围或删除）。默认三张时政地图为：
- **`2026.10国考时政地图`**：时政范围 `2025年10月至2026年10月上`
- **`2026.12省考时政地图`**：时政范围 `2025年11月至2026年11月上`
- **`2027.3省考时政地图`**：时政范围 `2026年1月至2027年2月上`

当用户提供或导入**月半时政**、**专题时政**、**冲刺学习**的 PDF 或文档时：
- 根据文档的**期数 / 发文时间**，自动归入对应时间范围的时政地图；
- 每个时政地图下的 `月半时政`、`专题时政`、`冲刺学习` 内容会自动保存为 Markdown 文档，存放在：
  - 行测库：`训练/万象峰/<时政地图名>/{月半时政,专题时政,冲刺学习}/*.md`
  - `gk-skill` 镜像：`gk-skill/时政地图/<时政地图名>/{月半时政,专题时政,冲刺学习}/*.md`

### 2. 用户发「政治理论」题目时的双重检索与出处标注规则
当用户发送**政治理论 / 时政题目**进行训练、答疑或复盘时，Agent 必须执行以下步骤：
1. **第一步：检索小黑政治理论 skill**（`gk-skill` 中的政治理论核心讲义与知识框架）；
2. **第二步：检索对应时政地图下的 `.md` 时政内容**（在 `时政地图/<时政地图名>/` 或 `训练/万象峰/<时政地图名>/` 的 `月半时政/`、`专题时政/`、`冲刺学习/` 中检索对应考点与原文）；
3. **第三步：明确说明出自哪个具体文件**：
   - 在解析中**必须注明考点和原文出自哪个文件**（例如：`出处：2026.10国考时政地图/月半时政/2026年9月·下.md` 或 `出处：小黑政治理论skill/<文件名>.md`），不能只给笼统解析。

### 3. 政治理论易错题集规则（不在思过崖显示，在时政地图「易错题」栏显示）
- 用户发的政治理论错题 / 易错题，**不放入思过崖七块石碑**，而是单独记录到政治理论易错题集：
  - `gk-skill` 路径：`gk-skill/错题集/政治理论.md`
  - 行测库路径：`训练/万象峰/易错题.md`（点同步或重进时自动同步）
- **文档格式**：严格采用思过崖错题集的格式模板（`## 编号 · 标题` → `### 题源与归属`（含出自哪个时政文件） → `### 原题`（题干 + `- A. ...` 选项） → `### 答案`（`- **正确答案**：X`、`- **我的选择**：Y`） → `### 解析与原文出处` → `### 错因与一句话教训`），在每个时政地图顶栏最后的 **「易错题」** 栏中按思过崖重做卡片样式展示与互动练习。

## 四、整场模考批量错题复盘规则（`mock-review` skill，只复盘错题）

用户说「复盘第 XX 季模考」或「复盘最新一次模考」时，**不要要求用户一道题一道题粘贴**，直接按 `gk-skill/skill/mock-review/SKILL.md` 执行批量复盘：

1. **只复盘错题（❌ / ⚪ 未答），不筛慢题**，自动兼容：
   - **粉笔 HTML/ZIP 导入**：`训练/试炼与大比/模考复盘/第XX季/`（及旧版 `训练/模考复盘/第XX季/`）
   - **PDF 拆分导入**：`FB模考试卷复盘/第XX季/`
2. **先用脚本抽题分包**：运行 `gk-skill/skill/mock-review/scripts/extract_mock_wrongs.py --vault "<行测库>" --season <季数> --out-dir /tmp/mock-review-<季数>`，自动按模块生成错题包并解析本地原图路径（图推/资料直接读图）。
3. **分板块分批 / 并行精讲**：按「政治理论 / 常识判断 / 言语理解 / 数量关系 / 判断推理 / 资料分析」分批（优先并发子 Agent），各自调用对应老师 skill；政治理论必须双检索并写明出处文件。
4. **自动回填 + 去重分流写回**：
   - 所有错题精讲回填至本季 `模考复盘/第XX季/` 对应题目的 `> **🧙 师傅解惑**` 区块（不覆盖用户原笔记）；
   - 政治理论错题 → `gk-skill/错题集/政治理论.md`（不进思过崖）；
   - 数量关系错题 → 十八讲对应课程 + `gk-skill/错题集/数量关系.md`（必写 `所属课程：第XX课-XXX`）；
   - 片段阅读（→ `中心理解.md`）、逻辑填空、定义判断、论证逻辑、类比推理、一拖五 → 思过崖对应 `.md`；
   - 图形推理 / 形式逻辑 / 资料分析 / 常识判断仅回填模考复盘文档并在总诊断报告中汇总，不写入思过崖 7 碑。
