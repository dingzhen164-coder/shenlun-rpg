# 整场行测模考批量错题复盘（`mock-review`）

## 触发时机
当用户提出以下任一需求时启用本 skill：
- 「复盘第 XX 季模考」/「帮我复盘第 XX 季错题」
- 「复盘最新一次模考」/「把刚导入的模考错题全部复盘一遍」

> **核心原则**：**只复盘错题（❌ / ⚪ 未答），不复盘做对的题，也不单独筛选慢题。**

---

## 第一步：用脚本一键提取该季全部错题（不要手工逐个翻文件）

运行同目录脚本 `extract_mock_wrongs.py`（自动兼容「粉笔 HTML/ZIP 导入」的 `训练/试炼与大比/模考复盘/第XX季/` 与「PDF 拆分导入」的 `FB模考试卷复盘/第XX季/`）：

```bash
# 查看可用季数
python3 gk-skill/skill/mock-review/scripts/extract_mock_wrongs.py --vault "<行测库路径>" --list

# 提取指定季数（或用 --latest 提取最新一季）并按板块拆成独立复盘包
python3 gk-skill/skill/mock-review/scripts/extract_mock_wrongs.py --vault "<行测库路径>" --season <季数> --out-dir /tmp/mock-review-<季数>
```

脚本会生成：
- `00-总览.md`：各板块错题数与分批清单
- `01-政治理论.md`、`02-常识判断.md`、`03-言语理解.md`、`04-数量关系.md`、`05-判断推理.md`、`06-资料分析.md`（仅生成有错题的批次）

---

## 第二步：按板块分批 / 并行精讲（严禁把 30~50 题塞进单次回复敷衍略写）

若当前 Agent 支持并发子任务（Subagent），**优先按板块并发启动子任务**（每个子任务只读自己对应的 `0X-*.md` 复盘包 + 对应老师 skill）；若不支持并发，则**逐个板块依次完成**，保证每道错题都有完整解析，绝不偷懒省略。

各板块必须遵守的检索与复盘标准：

1. **`01-政治理论`**：
   - **双重检索**：先查「小黑政治理论 skill」，再查对应时政地图下的 `.md`（`gk-skill/时政地图/<时政地图名>/{月半时政,专题时政,冲刺学习}/*.md` 或 `训练/万象峰/<时政地图名>/...`）。
   - **必须注明出处**：每道题解析必须明确写出考点与原文出自哪个具体文件（如 `出处：2026.10国考时政地图/月半时政/2026年9月·下.md` 或 `出处：小黑政治理论skill/<文件名>.md`）。
2. **`03-言语理解`（逻辑填空 / 片段阅读）**：
   - 调用言语理解 / 成语实词 skill；逻辑填空必须对比「我选的词 vs 正确答案」的语义侧重与语境对应点；片段阅读必须拆出文段结构（转折/因果/总分/对策）并指出我选错项的典型干扰类型（无中生有/以偏概全/非重点等）。
3. **`04-数量关系`**：
   - 对照「数量关系十八讲」确定**精确所属课程**（`第01课-方程思维` ～ `第18课-趣味杂题`）。
   - 给出「考场最快解法（代入/比例/赋值/公式）」+ 明确指出卡壳/算错的环节。
4. **`05-判断推理`（图形推理 / 定义判断 / 类比推理 / 论证逻辑 / 形式逻辑 / 一拖五）**：
   - **图形推理**：复盘包中已给出本地原图路径，**必须直接读取原图**后再讲规律（位置/样式/数量/属性/空间），严禁凭空猜图。
   - **论证逻辑**：写清论点、论据、选项削弱/加强方式，以及误选项为何属于无关/偷换/力度弱。
   - **定义判断 / 类比推理 / 一拖五**：指出漏看的关键要件、二级辨析关系或推理突破口。
5. **`06-资料分析`**：
   - 若复盘包中有材料图表原图，直接读取原图核对数据；写清题型（基期/现期/增长率/比重/平均数/倍数）、速算截位过程，以及错因（找错数/时间坑/单位坑/计算失误）。
6. **`02-常识判断`**：
   - 简明点出核心知识点与易混淆项，不做冗长展开。

---

## 第三步：自动回填与分流写入（严格去重，不破坏用户原笔记）

完成解析后，按以下规则落地写回：

### 1. 回填本季模考复盘原文件（所有板块必做，确保「宗门大比」复盘界面直接显示解析）
- **公考模拟器的「宗门大比 → 复盘 → 复盘解析」直接读取本季 `模考复盘/第XX季/[0-9][0-9]-<板块>.md`（或 `FB模考试卷复盘/第XX季/...`）中每题的 `> [!note] 复盘` 区块**。
- 为保证格式 100% 被软件识别且不破坏粉笔原解析与用户原笔记，**必须使用脚本批量回填**（不要手工正则乱改 `>` 引用）：
  ```bash
  # 将本批次全部错题的解析整理为 JSON：[{"file": "<原复盘文件>", "num": <题号>, "note": "<精讲解析+错因+一句话教训>"}, ...]
  python3 gk-skill/skill/mock-review/scripts/extract_mock_wrongs.py --write-batch /tmp/mock-review-<季数>/notes-<批次>.json
  ```
- 脚本会自动把解析按 `> **🧙 师傅解惑**（YYYY-MM-DD）` ～ `> <!-- /师傅解惑 -->` 写进对应题目的 `> [!note] 复盘` 中（若 PDF 拆分题原无 `> [!note] 复盘` 会自动补建；重复跑同题会自动替换旧块不堆叠）。写完后在软件里打开/刷新「宗门大比 → 复盘」，「复盘解析」里就能直接看到完整精讲。

### 2. 分流写入错题集（写入前先检查是否已存在同题号/同题干，避免重复）
- **政治理论错题** → 写入 `gk-skill/错题集/政治理论.md`（同步后在万象峰「易错题」栏显示，**严禁写入思过崖**），采用思过崖标准模板，并在 `### 题源与归属` 写明 `粉笔第XX季模考 第N题` 与**具体出处文件**。
- **数量关系错题** →
  1. 写入「数量关系十八讲」对应课程 `.md`；
  2. 同时写入 `gk-skill/错题集/数量关系.md`（思过崖），在 `### 题源与归属` 必须写明 `- **所属课程**：第XX课-XXX`。
- **思过崖其余 6 板块错题** → 按下表精确对应写入 `gk-skill/错题集/<文档名>`：
  - `片段阅读` → `中心理解.md`
  - `逻辑填空` → `逻辑填空.md`
  - `定义判断` → `定义判断.md`
  - `论证逻辑` → `论证逻辑.md`
  - `类比推理` → `类比推理.md`
  - `一拖五` → `一拖五.md`
- **图形推理 / 形式逻辑 / 资料分析 / 常识判断**：只回填本季模考复盘文件并在总诊断中汇总，**不写入思过崖 7 碑**。

### 3. 思过崖 & 政治理论易错题标准格式
```markdown
## <序号> · <简短考点标题>

### 题源与归属
- **来源**：粉笔第XX季模考 · 第N题
- **所属课程**：第XX课-XXX（仅数量关系必填）
- **原文出处**：<具体时政/skill文件名>（仅政治理论必填）

### 原题
<题干>
- A. ...
- B. ...
- C. ...
- D. ...

### 答案
- **正确答案**：X
- **我的选择**：Y

### 解析与对比
<结合对应 skill 的精讲 + 为什么我选的 Y 不对>

### 错因与一句话教训
- **错因**：...
- **一句话教训**：...
```

## 第四步：输出整场模考总诊断报告

全部板块写回完成后，向用户汇报一页简洁的总诊断：
1. **本场错题概览**：总错题数、各板块失分分布表；
2. **本场高频错因 Top 3**（跨板块提炼，如“逻辑填空忽略对应句”“论证混淆论点与论据”“资料时间坑”）；
3. **写回清单**：已回填的模考复盘文件数、新增写入思过崖/政治理论易错题/数量十八讲的题数；
4. **下一场模考前最值得优先补的 2～3 个点**。
